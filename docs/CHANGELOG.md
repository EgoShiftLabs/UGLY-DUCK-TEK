# Changelog

## V0.2.0 — Applied learning pathway

- Replaced shallow lesson summaries with six expanded learning tracks, each with three reading sections, objectives, a worked example, and a realistic failure pattern.
- Replaced simplistic multiple-choice items with thirty applied decision scenarios and explanations.
- Added four-part practical artifacts for all tracks, learner self-review rubrics, a private portfolio page and JSON export.
- Divided progress into knowledge checks and written exercises. Full practice completion now requires both in all six tracks, with no credential claims.
- Preserved V0.1 free-form notes and quiz scores while requiring new practical work for the applied-practice milestone.
- Replaced dense mobile navigation with a disclosure-controlled course menu.
- Removed third-party web font requests, introduced an in-document CSP, and expanded desktop/mobile browser automation.
- Updated GitHub Pages instructions and security/educational limitations.

No official certificate, identity system, NFT, wallet connection, real applicant admission, or payments were added.

## V0.1.0 — Independent practice foundation

- Six introductory learning tracks, thirty simple local questions, progress tracking, browser notes, editable practice export and GitHub Pages.
