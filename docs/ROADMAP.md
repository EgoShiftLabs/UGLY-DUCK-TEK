# UGLY DUCK TEK — Development Roadmap

## V0.1 Foundation — delivered

- [x] Independent static academy and GitHub Pages
- [x] Six short learning tracks, local quiz scores and practice export
- [x] Standalone browser storage and automated checks
- [x] Clear non-certification statements

## V0.2 Applied Practice — implemented in code

- [x] Expanded instruction, objectives, examples and failure patterns for six tracks
- [x] Four structured prompts and a local self-review rubric per track
- [x] Thirty practical decision scenarios and written explanations
- [x] Cumulative private portfolio view and separate portfolio export
- [x] Dual knowledge/practice progress and completion milestone
- [x] Preservation of previous V0.1 scores and notes without overstating completion
- [x] Mobile course-navigation toggle and non-JavaScript overview
- [x] System fonts and restrictive meta CSP; no third-party font network dependency
- [x] Expanded browser checks, including reset acceptance and cancellation
- [ ] Real phone and screen-reader accessibility review
- [ ] Pilot learner feedback and assessment of actual artifact quality

## Next version: validate learner outcomes

- [ ] Recruit 10–20 voluntary pilot learners across crypto and non-crypto interests.
- [ ] Record onboarding confusion, lesson completion, revision quality and mobile usability.
- [ ] Introduce worked critique examples and optional anonymous feedback.
- [ ] Refine scenarios based on misunderstandings, not just pass rates.
- [ ] Evaluate whether a mentor or peer-review pathway is practical and safe.

## Later: trusted credentials, only when justified

- [ ] Define clear competencies and independent evaluation rubrics.
- [ ] Build secure assessment records and an issuer with verified identity and revocation.
- [ ] Obtain qualified subject-matter review and legal/privacy guidance.
- [ ] Create an independent verification flow before connecting any membership or privileged action.
- [ ] Consider optional blockchain anchoring only if it materially improves portability or trust.

**Not in V0.2:** Paid certificates, NFT issuance, automatic BAGZ Forge admission, accounts, proctoring, or token launch functionality.
